UsageBeacon v1.4.0 can show your Antigravity Gemini quota next to Claude Code and Codex, and keeps the taskbar widget inside the taskbar.

## Highlights

- Turn on **Show Antigravity (Gemini) usage** in the popup settings to see the Gemini model group's five-hour and weekly limits, with reset times, in the popup, the taskbar widget, and the notification-area tooltip. The option is off by default.
- UsageBeacon reads the quota from the local Antigravity CLI report (`agy -p /usage --output-format json`). The report does not send a prompt, spend quota, or create a conversation. It needs agy 1.1.11 or later; older releases would treat `/usage` as a prompt, so UsageBeacon checks `agy --version` first and refuses to run the report on them. Run `agy update` if you see that message.
- Only the Gemini group is shown. Antigravity's separate quota for Claude and GPT models is not displayed.
- The report takes a few seconds, so it runs at most every two minutes unless you refresh manually. Claude Code and Codex values are shown without waiting for it.

## Other changes

- The usage popup and dashboard use the bundled official Claude and OpenAI images in place of placeholder symbols, including the dashboard cost breakdowns, chart legend, and model table.
- The widget stays inside the taskbar: it hides when no safe slot exists, comes back when space returns, and corrects DPI rounding from its actual window bounds. Its window fits the measured content with balanced padding.
- The dashboard's minimize, maximize, and close buttons look and behave like standard Windows caption buttons and stay on screen when the dashboard is maximized.

The Antigravity icon is Google's unmodified mark and identifies the displayed service; UsageBeacon remains an independent, unofficial project.

Download the self-contained `UsageBeacon.exe` below and compare its SHA-256 hash with `UsageBeacon.exe.sha256`. The executable is unsigned, so Windows SmartScreen may show a warning.
