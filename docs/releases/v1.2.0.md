UsageBeacon v1.2.0 makes locally recorded Claude Code and Codex activity easier to compare day by day.

## Highlights

- The dashboard now has an integrated title bar and keeps lifetime, today, last 7 days, and last 30 days at the top.
- Aligned cost and token charts show where usage spiked. Switch between 7 and 30 days, select a day for its exact figures, or read every day's estimated cost and token count below the charts without hovering. Chart axes use rounded intervals based on the displayed data.
- Switch estimated costs between USD, JPY, and EUR. JPY and EUR use fixed approximate display rates; the underlying estimate remains in USD.
- GPT-6 Astra and GPT-6 Sol now contribute to estimated cost using published Standard short-context API prices.

## Reliability and privacy

- Claude usage and OAuth responses now enforce their timeout and size limits through the complete response body, preventing a stalled body from blocking later refreshes.
- Crash-log redaction now handles complete quoted credential values, including whitespace and escaped quotes. Review a crash record before sharing it: redaction remains best effort for arbitrary exception text.
- Dashboard cost coverage is explained in words when pricing data or older source logs are missing.

## Before you download

Costs are API-price equivalents, not subscription charges. The dashboard uses session logs retained on this PC; it does not include cloud sessions or other devices. GPT-6 estimates use short-context rates because the local logs do not identify long-context requests or cache writes. The screenshots above use illustrative data.

Download the self-contained `UsageBeacon.exe` below and compare its SHA-256 hash with `UsageBeacon.exe.sha256`. The executable is unsigned, so Windows SmartScreen may show a warning.
