UsageBeacon v1.5.0 adds Antigravity CLI usage to the usage dashboard and updates the price table.

## Highlights

- The dashboard reads Antigravity CLI transcripts under `~/.gemini/antigravity-cli/brain` and adds an Antigravity share to the lifetime and period cards, the daily cost chart, the selected-day details, and the model table. Antigravity appears only after its logs contribute usage.
- Antigravity transcripts do not name the model on each step. UsageBeacon infers it from Antigravity's model-selection notices and falls back to the model in your Antigravity settings, so the split is an estimate. Only `transcript.jsonl` is read; the duplicate `transcript_full.jsonl` is skipped.
- As with Claude Code and Codex, the figures are API-price equivalents. Antigravity bills through plan quotas, not per token.

## Price table

- New: `gpt-6-luna`, `gemini-3.1-pro`, Gemini 3.6/3.7/3.8 Flash (including their 2027-01-01 increase), `claude-opus-5-5`, and `claude-sonnet-5-5`.
- Claude Opus 5.5 was previously priced as Claude Opus 5 through the prefix fallback; it now uses its own lower rate, so Claude Code estimates may drop.
- `gpt-5.6-sol`, `gpt-5.6-terra`, and `gpt-5.6-luna` now match OpenAI's published rates. Retained history is repriced at the new rates, so Codex estimates are lower than in v1.4.0.
