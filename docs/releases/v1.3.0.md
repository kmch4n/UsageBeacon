UsageBeacon v1.3.0 adds an optional wider taskbar widget and improves reliability across usage collection, settings, and the dashboard.

## Highlights

- Turn on **Show weekly usage in widget** to see five-hour and weekly percentages side by side for Claude Code and Codex. The option is off by default, and the numbers keep the same text size.
- The widget now uses bundled Claude and OpenAI images in place of placeholder symbols. These marks identify the displayed services; UsageBeacon remains an independent, unofficial project.
- The application and notification-area icon use a new multi-size beacon mark. The dashboard shows it in its title bar and taskbar entry.
- Widget placement checks the live notification-area boundary, keeps a 26 px gap, and moves outside the taskbar when a safe inline position cannot be verified.

## Reliability and privacy

- Unexpected startup and popup errors no longer display raw exception details that may contain local paths or credentials.
- Claude usage follows account changes and sign-out; transcript scans include files still being written.
- Codex app-server startup can recover after a failed initialization. Canceling a usage refresh no longer publishes a network error.
- Startup registration detects stale executable paths. Failed settings changes return to the accepted value and can be retried.
- The dashboard recovers from malformed insights-cache structures, keeps retained history visible when source log directories disappear, and ignores incomplete pricing overrides instead of treating missing prices as zero.
- The popup now displays the saved language on first open.

Taskbar button boundaries are cached for up to five seconds. A button that moves during that interval may briefly overlap the widget; the notification-area boundary is checked every 200 ms. The widget has not been visually verified at every Windows scaling and taskbar configuration.

Download the self-contained `UsageBeacon.exe` below and compare its SHA-256 hash with `UsageBeacon.exe.sha256`. The executable is unsigned, so Windows SmartScreen may show a warning.
