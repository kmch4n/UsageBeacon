UsageBeacon v1.6.1 fixes a console window that kept flashing while Antigravity usage was shown.

## Fixed

- **No more console flashes with Antigravity usage on.** With "Show Antigravity (Gemini) usage" enabled, a console window briefly appeared about every 15 minutes. It came from agy's own background self-updater, which UsageBeacon's usage check started. UsageBeacon now runs agy with its auto-update check disabled. agy still updates itself when you use it directly.

If you turned Antigravity usage off to avoid the flashing, you can turn it back on after updating.

Download the self-contained `UsageBeacon.exe` below and compare its SHA-256 hash with `UsageBeacon.exe.sha256`. The executable is unsigned, so Windows SmartScreen may show a warning.
